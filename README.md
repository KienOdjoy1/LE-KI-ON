## Project Description

LEKION is a simple web-based dictionary application. It allows users to search for an English word and see its meaning and other information.

The project is made using **HTML, CSS, and JavaScript**. It also uses the **Free Dictionary API** to get the dictionary information.

Our goal is to make a dictionary that is simple, clean, and easy to use.

---

## Features

- Search for an English word
- Display the word's definition
- Display pronunciation when available
- Display the part of speech
- Display example sentences when available
- Simple and easy-to-use interface
- Responsive layout for different screen sizes
- Uses an external API to get dictionary information
- No API key is needed

---

## How It Works

1. The user enters a word in the search box.
2. The application sends the word to the Free Dictionary API.
3. The API returns information about the word.
4. JavaScript processes the information.
5. The application displays the word, definition, pronunciation, part of speech, and examples when available.

---
   
## API Used

We use the **Free Dictionary API**.

API Website:
https://freedictionaryapi.com/

Endpoint:

https://freedictionaryapi.com/api/v1/entries/en/<word>

Example:

https://freedictionaryapi.com/api/v1/entries/en/hello

No API key is required.

An internet connection is needed because the application gets the dictionary data from the API.

## How to Run

No installation is required.

### Option 1: Open Locally

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Click the link or button to open the dictionary application.

### Option 2: Use the Online Version

You can access the project here:

https://kienodjoy1.github.io/LE-KI-ON/

An internet connection is required for the dictionary API to work.
